# 高保真原型图（Android）

本目录为 Android 端「语音任务四象限 App」高保真设计稿（中文）。

## 视觉规范
- 风格：清新轻量（C）
- 主色：蓝色（#2563EB / #3B82F6）
- 语言：中文
- 分辨率：1080 x 1920（适配 Android 评审）

## 预览方式（无需开发环境）
1. 直接双击 `index.html`。
2. 点击页面卡片打开对应 SVG。
3. 在 SVG 内通过热点点击完成流程演示。

## 可点击链路
- 看板 -> 任务详情
- 看板 -> 列表
- 看板 -> 新建
- 语音新建 -> 转写确认
- 转写确认 -> 任务详情
- 任务详情 -> 子任务编辑
- 列表 -> 任务详情

## 页面清单
1. `01_看板页.svg`
2. `02_语音新建页.svg`
3. `03_转写确认页.svg`
4. `04_任务详情页.svg`
5. `05_任务列表页.svg`
6. `06_子任务编辑页.svg`

> 建议使用 Chrome / Edge 浏览器查看，展示最稳定。


## 预览失败兜底（重点）
- 如果 `index.html` 或直接打开 SVG 无法显示，请改为打开 `prototype.html`。
- `prototype.html` 是单页预览器，顶部按钮切页，不依赖 SVG 内部链接。
- 若仍为空白，请换 Chrome/Edge（部分移动端内置浏览器不支持完整 SVG）。
